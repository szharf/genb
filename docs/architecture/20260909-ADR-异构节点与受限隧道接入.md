# 异构节点与受限隧道接入

日期：2026-09-09。适用于本次 47、18 双节点试点。

## 决策

保留 Python 直接启动和 Docker 镜像启动。控制面保存节点允许类型，节点探测保存可用环境；节点上的 root 所有策略文件再次执行类型、端口、磁盘与内存限制。

47 运行 GenB 控制面、数据库、Redis 和网关鉴权服务。18 继续运行统一 Nginx 与前端，并增加 Python 节点能力，不增加 Docker 或数据库。

实际测试中两台服务器间的新业务端口不能直接连通，47 主机 INPUT 为 ACCEPT，不能靠修改主机防火墙解决。因此采用现有 SSH 连通能力建立固定范围的受限反向隧道：

```text
浏览器 /agents/{id}/
        │
        ▼
18 Nginx ──鉴权──► 18:127.0.0.1:18700 ──SSH──► 47 网关鉴权:18700
        │                                        │
        │                                        ├─47 GenB:8581
        │                                        └─47 Redis:6379
        │
        ├─18 实例：127.0.0.1:18000—18099
        └─47 实例：127.0.0.1:28000—28099 ──SSH──► 47:18000—18099
```

网关返回的是 **18 Nginx 能访问的代理地址**。47 节点使用 `proxyTargets=127.0.0.1`、`proxyPortOffsets=10000`；18 节点使用本机地址且无端口偏移。快照中的端点与发布路由必须匹配，不能把鉴权服务所在机器误认为业务代理所在机器。

隧道仅绑定 18 loopback，专用公钥只允许认证入口和 47 的固定端口池。每个智能体不创建新 SSH 账号、专用 Nginx location 或网关代码分支。新节点接入时，由运维一次性配置可信地址、连接、端口池和节点资源策略。

## 发布一致性

普通智能体独立生成路由，无需绑定核心组件。快照 schema 1.1 增加 `endpoints`，保留 1.0 兼容。版本单调递增，完整快照不可变；非法快照不覆盖最近有效配置。

发布和撤下使用预期版本与持久化幂等键。控制面收到网关应用确认后才显示 APPLIED；确认心跳超过十五秒不再显示已生效。停止当前路由实例前，必须完成撤下与确认。客户端对受管实例只使用网关入口，不回退裸端口。

## 运行与限制

Python 每实例独立用户、目录、venv 与 systemd 单元。依赖安装同样非 root，使用 oneshot 构建单元以兼容 47 的 systemd 239。Docker 支持经典与 OCI 布局的单镜像 docker-save TAR，并验证配置摘要。

部署任务持久化，启动中断进入 UNKNOWN 并核对远端；不重复创建同一实例。当前是单控制面调度器，多个独立控制面副本并发调度不在本次范围。

固定端口池是现有网络限制下的试点连接方案，规模增长时应改用经批准的私网或 VPN 路由。当前不承诺高可用、多副本、自动迁移、滚动替换和自动清理。失败端口保留用于排查。

当前公共入口使用 `http://18.167.156.11`，尚未新增智能体 HTTPS 域名或证书。统一网关身份并不自动实现应用内部的业务数据隔离。
