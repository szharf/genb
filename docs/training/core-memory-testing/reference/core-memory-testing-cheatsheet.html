页面最小通过矩阵

用例操作差异预期
短期首次A + 新 Session召回 0，提交后 2
短期连续A + 同 Session召回 2，提交后 4
Session 隔离A + 新 Session召回 0
智能体隔离B + A 的 Session + B 凭证召回 0
错凭证页面选 A + B 凭证403/身份不匹配
长期写入A + 稳定偏好SUCCEEDED，写入 1
长期跨 SessionA + 新 Session + 同主题查询仍能召回

四个输入

绑定智能体记忆归属；只能选已启用绑定
Session ID短期隔离边界；由测试者创建，首轮务必唯一
服务凭证每个智能体一份长期机器身份；页面生成后只展示一次，测试框提交后清空但凭证仍有效
用户消息测试内容；禁止真实密码、Token、验证码、API Key

当前能力边界

本地 Runtime 使用 Fake 结构化结果，能证明接口、配置、提取、持久化和隔离链路，不能证明真实模型回答质量。长期记忆页面会先提取再搜索，严格 A/B、敏感拒绝和删除矩阵应运行 CLI acceptance。

出错先看

403登录 Token、用户权限、A/B 凭证归属、scope、绑定启用状态
无可选智能体该组件没有已启用绑定
短期一直为 0是否换了 Session、agentId 或 Redis DB
长期卡住Control Worker、Runtime ready、PostgreSQL、任务状态
遇到不一致时保留时间、智能体、Session、HTTP 状态、错误原文和截图，再向 Codex 提问；不要记录服务凭证明文。
