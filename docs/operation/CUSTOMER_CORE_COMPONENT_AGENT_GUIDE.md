# 18714智能体能力体验手册

> 面向不懂技术的客户和业务验收人员。测试地址：`http://localhost:18714/`。

## 1. 怎么开始

1. 打开`http://localhost:18714/`。
2. 如果进入统一登录页，正常登录即可，完成后会自动返回。
3. 左侧选择一个体验场景。
4. 阅读智能体的第一句话，像平时聊天一样回复。

页面会自动维护测试所需的内部标识，不需要填写Task ID、Session ID、JSON或操作码。三个场景的对话互不混用；每个场景上方会保留该用户的对话历史，点击“开始新测试”或“新建对话”会新增对话，不覆盖旧对话。

## 2. 场景一：记住本次交流

这个场景测试智能体能否记住同一次交流中刚说过的话。

1. 点击“记住本次交流”。
2. 点击建议回复“我正在为A公司办理授信，我偏好低风险方案”，或输入自己的内容。
3. 点击“发送”。
4. 智能体确认记下后，点击“我刚才告诉了你什么？”。
5. 再次发送。

成功时，智能体会复述第一轮内容，并明确显示“本次交流记忆验证成功”。右侧三步全部变为绿色对勾。

## 3. 场景二：跨会话记住我

这个场景测试智能体在换一个新会话后，能否找回以前保存的稳定偏好。

1. 点击“跨会话记住我”。
2. 点击建议回复“我长期偏好稳健、低波动的授信方案”，或输入一个长期、稳定且不敏感的偏好。
3. 发送并等待智能体确认保存。
4. 点击对话中的“新建对话并验证”。上方会立即出现第二条对话，第一条对话仍然保留并可切回。
5. 点击“你还记得我的长期偏好吗？”并发送。

成功时，智能体会说明这是一个新对话，同时列出以前保存的偏好，并显示“跨会话长期记忆验证成功”。刷新页面后再次进入长期记忆场景，两条对话仍应存在。

不要输入密码、验证码、Token或其他敏感信息。此处测试的是Conversation Memory；Knowledge Base尚未接入，不会把知识库能力冒充为已完成。

## 4. 场景三：一步步生成Skill

这个场景测试智能体是否会先理解需求、继续追问，信息完整后才生成Skill。

1. 点击“一步步生成Skill”。
2. 点击“我想生成一个银行对公授信材料检查Skill”，或描述自己的目标。
3. 等待智能体提出需要确认的问题。
4. 可以自己回答，也可以点击“填入一份完整回答示例”后发送。
5. 如果智能体继续追问，按问题补充材料范围、判断标准、输出形式和人工处理规则。
6. 信息足够后，智能体会自动生成Skill卡片，显示名称、版本和正文。

成功时需要同时满足：

- 需求不完整时没有直接伪造Skill，而是继续提问。
- 问题与当前业务有关，不是固定的技术表单。
- 信息完整后出现Skill结果卡片。
- 右侧“说出想生成什么、回答澄清问题、生成并检查Skill”全部打勾。

## 5. 页面怎么看

- 中间是主对话区，所有测试都从这里完成。
- 输入框上方可能出现建议回复，点击只会填入内容，不会自动发送。
- 右侧显示测试目标、当前进度和成功标准。
- “查看技术验证详情”默认折叠，只供开发和验收人员复核真实调用；普通用户不需要阅读。

## 6. 常见问题

- 一直显示“思考中”：规划和Skill生成可能需要几十秒；不要重复点击发送。
- 长期偏好没有保存：换成明确、稳定、非敏感的表达再试。
- Skill继续追问：说明关键规则仍不完整，按当前问题继续回答即可。
- 页面提示登录失效：重新通过统一门户登录，现有安全链路仍使用一次性授权码、服务端Redis会话和HttpOnly Cookie。
- 要重新体验：点击右上角“开始新测试”，只会清空当前场景。

## 7. 设计参考

本页面采用“对话为主、阶段引导、结果卡片、技术证据折叠”的组合模式，参考了：

- OpenAI ChatKit的对话线程、来源标注和对话内卡片。
- Microsoft Copilot Studio的连续对话测试方式。
- Intercom Fin的澄清、回答和次级答案检查信息。
- Dialogflow CX把真实对话保存为测试案例的方式。

## 8. 当前唯一入口和登录安全

- 客户只使用`http://localhost:18714/`；不要再使用`http://localhost:9100/core-agent/`，旧地址只返回`410 Gone`，不提供兼容页面。
- 统一门户只向智能体回调一次性授权码；智能体换票后在Redis保存服务端会话，浏览器只得到不透明的`HttpOnly + SameSite=Lax` Cookie。
- 门户Token、服务凭证、授权码和Session Grant都不会显示在客户页面，也不能复制到对话框。
- 本地轮换智能体服务凭证后，必须同步重启18714和使用该凭证白名单的18704 Runtime；否则登录换票或Skill模型调用会返回401。
