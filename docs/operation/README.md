# 运维文档

本目录用于记录运行、监控、排障、数据库、Nginx、Docker 和服务器相关说明。

服务器操作默认高风险。临时冻结、演示期、发布窗口必须写明具体起止日期；只有未过期的冻结窗口才作为当前操作限制。

## 专项操作手册

| 文档 | 说明 |
|---|---|
| `CORE_MEMORY_TESTBENCH_AND_TEST_AGENT_GUIDE.md` | 长短期记忆独立测试台与测试智能体逐点击、逐输入操作，覆盖服务启动、凭证、A/B 隔离、验收矩阵、证据和排障。 |

## 运维对象

| 对象 | 说明 |
|---|---|
| 前端 Nginx | 管理 `/genb/` 和 `/genb-client/` 静态资源与 API 转发。 |
| 后端 Spring Boot | 提供登录、权限、智能体、审批、状态接口。 |
| PostgreSQL | 存储用户、角色、权限、智能体、授权、申请、运行状态。 |
| Docker 智能体 | 通过镜像状态判断是否启动。 |
| Python 智能体 | 通过运行状态字段和端口判断是否启动。 |

## 常见故障和排查路径

| 现象 | 优先排查 |
|---|---|
| 页面空白，JS MIME 是 `text/html` | Nginx 静态资源路径、前端 base、dist 是否部署到正确目录。 |
| 登录 404 | 前端 API base URL、Nginx API 转发、后端 context-path。 |
| 登录 403 | 后端权限、角色、CORS、认证接口。 |
| 智能体列表超时 | 后端是否实时查询智能体运行状态；应优先查数据库缓存状态。 |
| 已启动智能体排到后面 | 排序规则是否按可打开/启动状态优先。 |
| Docker 智能体显示未启动 | 镜像状态字段和容器名称匹配规则。 |

## 数据库运维原则

- 日常开发默认本地数据库。
- 服务器数据变更必须明确目标库、schema、表。
- 插入、更新、删除前先查询确认。
- 涉及未过期冻结窗口时不要批量操作；冻结窗口必须有具体起止日期。
- 变更 SQL 和结果写入 `records/deployments/` 或 `records/reports/`。

## Nginx 运维原则

- 不修改无关项目 location。
- 修改前备份。
- 修改后 `nginx -t`。
- reload 后验证已有管理端和新增客户端都可访问。

## 智能体状态运维原则

- Python 智能体：看运行状态字段。
- Docker 智能体：看镜像状态字段，例如 `1/1`、`2/2`。
- 未配置访问端口的智能体不能作为可打开能力展示。
- 状态实时探测应避免每次列表查询都触发，防止页面超时。
