# GenB 核心组件详情治理视图 Iteration 7 实施报告

## 一、结果

在 Iteration 6 固定五系统/14组件目录页基础上，完成组件详情治理视图。管理员现在可以点击任意组件卡片进入稳定 URL，并在一个页面查看该组件的服务实现、配置版本、智能体绑定和最近管理审计。

本轮是只读治理视图，不提供伪造数据和未接后端的按钮。远程库目前实现、配置和绑定为空时，页面明确展示空状态。

## 二、后端

新增：

```text
GET /v1/core-components/{componentCode}
权限：component.read
```

响应包含：

- `component`：固定目录信息。
- `implementations`：服务实现元数据。
- `configVersions`：安全配置版本摘要。
- `bindings`：智能体绑定元数据。
- `audits`：最近 200 条治理审计。

配置摘要刻意不包含 `config`、`configJson`、`secretRefs` 和服务凭证明文。真实 HTTP 响应已经检查不存在这些字段。

后端使用现有表和逻辑关联，只增加 Repository 只读查询，不新增表、字段或物理外键。

## 三、前端

新增详情路由：

```text
/core-components/:componentCode
```

页面组件拆分为：

- 详情容器和请求 composable。
- 组件身份/状态/数量头部。
- Implementation 表。
- 配置版本表。
- 智能体绑定表。
- 管理审计表。

组件卡片同时支持鼠标点击、Enter 和 Space 键进入详情。详情页支持刷新、失败重试和返回目录。
