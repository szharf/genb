## 交付范围

- 部署页：Python ZIP / Docker TAR、节点能力筛选、上传进度、后台真实阶段、历史材料复用。
- 运维页：部署结果、实例运行状态、访问入口状态分别展示；启停、重启、重新部署、日志、入口发布/撤下、实例回收、任务进度与继续核对。
- 删除：节点项目采用归档，撤入口并等待网关确认，再停止和回收全部实例；保留部署/运维历史及节点业务目录。
- 幂等任务：持久化操作标识和阶段；进程重启后继续处理未完成任务，失败后由管理员继续核对；不把远端超时当成功。
- 端口：只有节点确认载体已回收后才清空控制面端口预留。停止不会释放端口。
- 状态核对：后台轮询实例和 HTTP 健康状态；断连显示 UNREACHABLE 并保留端口。运维与部署使用独立调度线程，依赖安装不占用运维线程。

旧项目继续使用原执行接口。有旧部署记录的项目不得直接切换节点托管，应继续原方式或新建节点项目，避免旧载体遗留。本次不包含旧部署数据自动迁移。
