# 部署运维页面体验修正

日期：2026-09-15。针对生命周期版本发布后的四项界面反馈进行补充修正。

## 问题与结果

1. 操作列混用按钮尺寸，且下拉触发器参与行内基线排版，导致“更多”偏大、偏上。统一使用水平居中布局、13px 字体、24px 按钮高度；两类项目一致。
2. 多节点运维从表格入口改为“当前部署与访问 + 生命周期管理 + 运行日志”，保留实例、入口发布和任务历史。布局与旧运维页接近；旧项目的本地命令编辑与多节点部署参数仍有不同含义，不强行合并。远程 CPU/内存实时曲线尚未新增。
3. 原部署页面默认空表单实际用于创建新版本，容易被误认成当前配置丢失。现优先显示入口指向实例的节点、类型、端口、入口、内存限制与实时访问状态；展开新版本时复用历史配置和材料，端口留空以要求选择空闲端口。首次加载期间不显示空的新建表单。历史任务描述明确标注为历史结果，不代表实时入口状态。
4. 部署/运维顶部新增“进入项目”。只有已确认 APPLIED 且地址与当前项目相符才可点击。修复客户端卡片把 /agents/... 网关地址误交给 Vue 内部路由的问题。

## 验证

- 控制台 Node 测试 25 项全部通过；客户端 Vitest 60 项全部通过。新增当前实例配置选择、损坏历史配置、入口状态/地址限制，以及卡片点击实际调用浏览器打开的回归测试。
- 控制台和客户端的中英文构建全部通过；客户端包含 TypeScript 检查。构建存在已有的大文件体积提示。
- 本地隔离接口浏览器验证：两行项目各四个按钮 y 坐标相同、高度 24px、字体 13px；部署默认不显示新建表单；当前配置和入口正确；复用后材料免重新上传、端口空时提交禁用；运维日志读取成功；无页面横向溢出、无控制台 error。
- 18 上四个发布目录 index.html SHA-256 与本地构建一致。管理端中英文、客户端中文、统一门户、GenO、FIBO 首页均 HTTP 200；联合推理实例 systemd 状态 active。
- 独立无登录浏览器访问联合推理统一入口，会转到 /genb-client/agent-sso 登录页，未绕过登录。未使用业务账号验证登录后的完整 LLM/Fuseki 流程。
