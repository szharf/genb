## 讲解假设

- 图中网关鉴权应用及隔离 Redis 放在 47 是容量待核验的建议示例，尚未定为生产部署位置。
- 18 保留 Nginx 与静态页面，通过内部鉴权服务取得目标，直接代理智能体字节流。18 仍有带宽和连接容量约束。
- 首版 47 通过受控 SSH/SFTP 管理新节点，节点部署受限执行入口，无需常驻任务领取服务。
- 新节点以 Docker 镜像归档运行智能体，不需重复安装完整 GenB Java 后端或平台数据库；应用专属数据依赖仍需单独规划。
- Java 17、Python 3.11+来自 pom.xml / pyproject.toml，不代表已实时核验服务器安装版本。网关容器交付需生产化验证。

## 代码定位

路径以父仓库为根：

- gen-b/gen-b-console/src/components/agent/AgentDeploy.vue、AgentRuntime.vue：上传部署与运行管理。
- gen-b/gen-b-client/src/utils/agentLaunch.ts、src/api/clientAgents.ts：固定入口与可用状态。
- gen-b/gen-b-backend/src/main/java/com/genb/console/controller/DeployController.java、DockerController.java：统一节点执行调用入口。
- 同后端 service/AgentService.java、ProcessManagerService.java：盘点本机操作，按节点与实例管理。
- 同后端 service/DataPlaneConfigService.java、entity/Agent.java、AgentDeployment.java：独立路由、内部目标和节点关联。
- genb-data-plane-gateway/genb_gateway/factory.py、routing.py、runtime_state.py：受控动态端点和配置生效。
- genb-data-plane-gateway/nginx/genb-gateway.local.conf：通用代理参考，不能直接覆盖生产共享 Nginx 配置。
