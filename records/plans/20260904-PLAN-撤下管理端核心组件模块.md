# 撤下 GenB 管理端核心组件模块计划

日期：2026-09-04

## 目标与范围

- 重新构建并部署 GenB 中文、英文管理端。
- 管理端不再展示“核心组件 / Core Components”菜单。
- `/genb/core-components...`、`/genb-en/core-components...` 历史地址不再加载未完成页面，统一返回仪表盘。
- 生产构建不再生成核心组件页面的异步代码块。
- 保留尚在开发的核心组件源码，避免丢失后续研发成果。
- 不修改或部署客户端、后端、数据库、Nginx和核心组件模型。

## 组件职责

| 文件 | 本次职责 |
|---|---|
| `src/layouts/navigationModel.js` | 移除核心组件菜单注册和标题映射 |
| `src/layouts/MainLayout.vue` | 移除核心组件菜单项渲染 |
| `src/router/index.js` | 移除核心组件页面懒加载路由；历史路径重定向到仪表盘 |
| `src/api/index.js` | 移除核心组件 API 的公共导出，避免进入主构建依赖 |
| 管理端契约测试 | 锁定菜单、路由和公共 API 均未暴露核心组件模块 |

本次没有新增组件，也不改变现有组件的数据流。

## 实施步骤与门禁

### M1：失败基线与契约测试

- 更新导航模型测试，期望智能体中心只保留智能体列表。
- 新增生产可用模块契约测试，检查核心组件视图不再被路由导入、公共 API 不再导出，并要求历史路径存在安全重定向。

验收：修改实现前测试失败，能够捕获当前已部署模块。

### M2：移除生产注册

- 删除菜单项、标题映射、两条核心组件页面路由和公共 API 导出。
- 增加历史核心组件路径到仪表盘的重定向。
- 保留 `components/core-components`、相关 composable、API 文件和 i18n 文案源文件，供后续继续开发，但生产入口不可达。

验收：专项契约测试通过。

### M3：构建与产物检查

- 执行管理端现有 Node 测试。
- 执行 `npm run build:zh` 和 `npm run build:en`。
- 扫描两套 `dist`，确认不存在核心组件视图代码块或 API 路径，同时核对 `/genb/`、`/genb-en/` 构建 base。

验收：测试、双语构建和产物扫描全部通过。

### M4：受控部署与回归

- 实时核验 `/app/frontend/genb/dist`、`/app/frontend/genb-en/dist` 与 Nginx 当前指向。
- 对两套线上目录做带时间戳备份，只替换管理端中英文静态产物。
- 验证首页、静态资源、历史核心组件深层地址及其他项目入口。

验收：中英文管理端正常访问，历史核心组件地址回到仪表盘；客户端、统一登录、GenC、GenO、FIBO及官网不受影响。

## 回滚

1. 恢复本次部署前备份的中文、英文管理端目录。
2. 不修改 Nginx，因此无需回滚网关配置。
3. 回归 `/genb/`、`/genb-en/` 与其他项目入口。
