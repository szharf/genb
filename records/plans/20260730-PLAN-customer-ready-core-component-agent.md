# 客户可验收的核心组件智能体与真实模型链路计划

> 日期：2026-07-30
> 状态：已完成
> 范围：GenB控制面、Runtime System Inference Engine、Planning & Reasoning、Short-term Memory、独立测试智能体

## 1. 背景与问题

当前实现已经证明GenB组件目录、实现、配置、绑定、服务凭证、Actor Token以及长短期记忆和规划服务的HTTP链路可以工作，但仍有三项验收缺口：

1. 智能体页面由`gen-b-client`承载，独立智能体项目只有后端，没有自己的客户级前端。
2. 页面要求手工选择规划操作并输入结构化参数，更像开发接口测试台，不是客户可用智能体。
3. 智能体回答使用`DeterministicAnswerer`，规划服务使用固定模板，尚未真实调用大模型。

本任务不删除既有管理端和开发测试入口；它们继续用于组件级诊断。本任务新增一条客户可验收的纵向链路。

## 2. 目标架构

```text
客户浏览器
  -> 独立核心组件智能体（独立前端 + 后端）
     -> GenB申请组件会话并解析已绑定实现
     -> Short-term Memory准备上下文
     -> Runtime Inference Engine调用真实模型理解/回答
     -> Planning & Reasoning在规划意图下澄清并生成Skill
        -> Runtime Inference Engine调用真实模型生成结构化结果
     -> Short-term Memory提交本轮上下文
  <- 客户回答 + 可选脱敏调用详情
```

职责保持不变：GenB是控制面；三个运行服务拥有各自Implementation；智能体负责编排；Provider密钥只由Runtime System持有。

## 3. 公开行为和验收场景

### A. 普通聊天与短期记忆

1. 客户输入“我正在为A公司办理授信，偏好低风险方案”。
2. 智能体真实调用模型回答并提交短期记忆。
3. 保持`taskId`、更换`sessionId`后询问“我在为哪个公司办理什么业务”。
4. 回答能够使用此前上下文；调用详情显示短期记忆命中和真实模型信息。

### B. 规划与Skill生成

1. 客户输入“帮我生成授信材料检查Skill”。
2. 信息不足时智能体自然追问输入、输出、约束和工具需求。
3. 信息完整后调用规划组件，由真实模型生成Skill草稿并通过确定性安全校验。
4. 客户看到可读Skill和说明，不看到内部操作枚举或请求JSON。

### C. 安全和绑定负向路径

- 停用任一所需组件绑定后，智能体明确返回能力暂不可用，不绕过GenB直连服务。
- 错误智能体凭证、错误用户权限、过期Actor Token均失败。
- 浏览器网络请求、页面源码、返回体和日志均不出现服务凭证或Provider API Key。

## 5. 实施约束

- 不使用旧Runtime SDK；只复用稳定HTTP契约和薄客户端。
- 不把模型调用强塞进短期记忆的纯存取路径；真实智能体必须调用模型，规划组件必须调用模型，记忆摘要等语义能力按需调用。
- 规划组件只负责澄清、生成、校验和修订，不负责执行Skill或MCP。
- Provider密钥从现有本机私密配置读取并注入Runtime进程，不复制到Git或普通日志。
- 数据表设计可以描述逻辑外键，真实迁移不创建物理外键。
- 不部署生产、不推送远端；本轮只在本地完成开发和验收。
- 保留用户和同事已有未提交文件；提交时逐文件精确暂存。

## 6. 组件边界

### 独立智能体

公开Interface尽量小：`POST /api/customer/chat`接收`taskId/sessionId/message`，返回客户回答、可选Skill结果及脱敏诊断。内部隐藏组件会话、路由解析、模型Prompt和各组件操作。

### Planning & Reasoning

公开Interface保持现有四种操作兼容。内部新增Inference Port，模型负责语义分析和内容生成，确定性代码继续负责输入门禁、Skill结构校验、版本、幂等和持久化。

### Short-term Memory

继续提供确定性的存取、隔离、TTL、幂等和脱敏，不因基础存取引入模型故障。语义摘要属于可选上层能力。

### Runtime Inference Engine

继续作为唯一Provider Adapter所有者。智能体和规划服务只依赖逻辑模型别名，不接触厂商协议和密钥。

## 7. 完成定义

只有当非开发人员从独立智能体页面完成两类验收场景、后台证据证明三项绑定和真实模型调用均生效、负向路径无法绕过、所有自动化与构建通过后，才能将本任务标记完成。
