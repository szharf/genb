# 页面新增服务器接入任务计划

- 模板版本：2.0；计划版本：1.0；档位：架构扩展（新增服务器连接和初始化权限边界）。
- 日期：2026-09-21；状态：开发及发布完成，真实新服务器接入验收待具备目标服务器后执行；负责人：Codex；范围：GenB 管理端、后端及节点接入程序。
- 依赖：现有 OpenSSH、Python 节点程序、节点管理及动态网关发布机制。

## 首页摘要

- 问题：原新增页面要求事先配置 SSH 别名，只能登记准备好的节点。
- 交付：自动编号的接入向导、服务器身份确认、连接检查、受控初始化、检查启用及详细提示。
- 不包含：自动开通云服务器/安全组、自动创建跨网络隧道、覆盖已有节点策略、承诺任意 Linux 发行版可安装。
- 当前进度：向导、接入程序和后台接口已实现，已部署 47 后端及 18 中英文页面；真实接口和浏览器检查通过。目标服务器初始化仍需实际新主机验收。
- 待决：没有新的可初始化服务器，生产既有 18/47 不能用于覆盖安装测试；用隔离测试环境验证执行逻辑，正式新增主机仍需逐台检查。

## 背景与事实基线

RuntimeNodeService.register 仅接受 trusted-targets 中别名；RemoteNodeClient 调用固定 SSH 命令。现有 install-node.sh 可安装节点程序、策略和专用账号。网关默认可直接使用节点 businessHost，无需逐项目修改代码；网络可达性仍需实际项目验收。

## 假设与方案

控制面为单台 Linux 服务器，接入状态及 SSH 私钥存放在配置的受保护持久目录。使用现有 OpenSSH/Python，不引入新的 SSH SDK。新节点直接连接模式；特殊隧道仍使用既有运维接入路径。

采用平台生成公钥的连接方式：用户将公钥授权给目标服务器上的初始化账号，页面无需提交密码或私钥，当前 HTTP 入口也不会传输这类秘密。凭据授权是服务器所有者的一次性操作，不是预先修改平台 SSH 别名。首次接入必须比对并确认主机指纹。

## 架构、权限与状态

- 管理员访问后端接入接口；所有服务器地址、端口、账号、资源限制由服务端校验。
- 后端调用固定接入脚本，参数通过标准输入传递，不将页面值拼接为可执行命令。
- 自动生成节点编号和两套密钥：初始化密钥、仅执行节点固定命令的运行密钥。私钥不返回浏览器。
- 接入状态写入权限 0700 的持久目录，文件 0600；原子写入、每任务锁，刷新可恢复任务。失败保留诊断，禁止重复初始化并发。
- 启用后复用 RuntimeNode、监控和部署，不修改既有节点的连接方式；托管 SSH 配置优先匹配自动生成节点。
- 状态区分草稿、指纹待确认、连接通过、初始化中、初始化失败、待启用、已启用。进程中断必须标明需要检查，不能假报成功。

## 需求与验收

| ID | 功能 | 验收 |
|---|---|---|
| R1 | 名称、IPv4、SSH端口、初始化账号、能力与资源规则 | 中文名称可用；标识自动生成；重复地址、非法地址和参数就地报错 |
| R2 | 公钥授权及主机指纹核验 | 私钥不出后端；身份确认前不能登录执行初始化；指纹变化连接拒绝 |
| R3 | 检查连接与安装前检查 | 区分网络、认证、sudo、系统环境、既有节点保护；给出修复方法 |
| R4 | 显式确认安装 | 仅执行受控安装脚本；已有节点和策略不覆盖；18/47既有业务不受影响 |
| R5 | 启用与后续验收提示 | 实际 probe/metrics 通过才进入节点目录；提示项目部署及网关访问仍待样例验证 |
| R6 | 页面说明、异常和恢复 | 步骤、字段帮助、按钮禁用原因、刷新恢复、重试均可见；中英文支持 |

## 页面与组件

NodesPage 只负责打开接入向导和刷新目录；NodeOnboarding 负责表单、步骤及任务状态；旧 NodeEditor 继续编辑已登记节点。后端接入控制器校验权限和节点冲突，固定 Python 接入程序负责 SSH 身份、任务持久化和安装。RemoteNodeClient 复用新连接配置。

## 执行与验证矩阵

1. 写页面流程与提示文档，开发参数校验、状态恢复、SSH 与既有节点保护。
2. 开发向导及后端接入、节点启用，复用部署和监控。
3. 测试无效输入、重复地址、身份变化、认证失败、并发、已有节点保护及敏感信息不泄漏。
4. 浏览器验证步骤与错误提示，中英文构建，既有部署与节点回归。
5. 发布前保留程序、配置和前端备份；已有节点仅只读验证，不重新初始化。

## 风险与回退

包管理器、网络隔离、sudo 策略或发行版不兼容时停止并给出步骤；不绕过权限。安装系统依赖不是事务，失败不自动卸载共享依赖。回退前端和后端可恢复旧登记流程；保留托管节点连接目录和运行程序，避免令已接入节点失联。无数据库结构迁移。
