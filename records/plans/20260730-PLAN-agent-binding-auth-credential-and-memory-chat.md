# 智能体绑定、统一退出、测试凭证与短期记忆聊天智能体计划

> 日期：2026-07-30
> 范围：GenB管理端、GenB客户端、`control-system-test-agent`
> 本地入口：`http://localhost:9100`

## 1. 目标

1. 核心组件绑定表同时显示智能体名称和ID。
2. 管理端、客户端退出后统一进入`/portal/login`。
3. 管理端无有效本地登录Token时，不得渲染`/genb/dashboard`等受保护页面。
4. 智能体绑定测试按智能体保存并自动回填服务凭证，真实调用后保留凭证。
5. 将`standalone-memory-test-agent`实现为可聊天的真实测试智能体，通过GenB绑定鉴权调用短期记忆服务。

## 2. 关键边界

- 不修改既有`9100`用户入口、`9000`内部管理端上游结构。
- 不在数据库新增明文凭证字段；测试台凭证仅保存在当前管理员浏览器本地存储。
- 后端历史凭证只保存哈希，无法反查明文；首次没有本地副本时仍需轮换一次。
- 聊天页面不接触服务凭证。长期服务凭证只由测试智能体进程通过环境变量读取。
- 每轮聊天必须经过：用户JWT + 智能体服务凭证 → GenB组件会话 → Actor Token → 短期记忆取上下文 → 回答 → 短期记忆提交。
- 实际数据库表不增加物理外键。

## 3. 前端组件边界

| 模块 | 单一职责 |
|---|---|
| `CoreComponentBindingTable` | 展示绑定对象名称、ID、实现、配置和状态 |
| `useCoreComponentGovernance` | 加载智能体目录并为绑定展示提供名称映射 |
| 凭证本地存储模型 | 按agentId保存、读取、删除管理员测试凭证 |
| `CoreComponentTestForm` | 自动回填凭证、轮换后保存、调用后保留 |
| Console Router Guard | 无Token时在页面渲染前跳转统一门户 |
| Client Auth/Shell | 清理两端登录状态并跳转统一门户 |
| `AgentChatView` | 路由级页面组合与智能体身份校验 |
| `AgentChatPanel` | 消息列表、任务/会话输入、发送状态 |
| `useAgentChat` | 调用智能体API并维护消息状态 |

## 5. 完成标准

- 绑定页能看到`standalone-memory-test-agent`的名称和ID。
- 两端退出均进入`http://localhost:9100/portal/login`。
- 退出后直接输入`http://localhost:9100/genb/dashboard`不会进入管理页面。
- 选择智能体后自动出现已保存有效凭证，调用完成后字段不清空。
- 客户端可进入该智能体聊天页；同一任务、同一会话第二轮能读取第一轮上下文。
- 未绑定、凭证错误或Token失效时明确失败，不绕过GenB校验。
- 所有相关自动化、构建和真实浏览器验收通过。
