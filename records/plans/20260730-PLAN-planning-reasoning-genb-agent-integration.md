# 规划与推理引擎接入 GenB 与测试智能体任务计划

## 1. 目标

- 将已完成的 `PLANNING_REASONING` 服务按正式 OpenAPI 契约注册到 GenB。
- 注册并启用 `PLANNING_REASONING_V1` 实现，发布配置，绑定专用测试智能体。
- GenB 核心组件详情页同时支持“管理员服务直测”和“智能体绑定测试”。
- 专用测试智能体通过长期服务凭证向 GenB 申请组件会话，使用 GenB 返回的实现地址和 Actor Token 真实调用规划服务。
- 提供面向用户的规划测试页面，覆盖需求澄清、Skill 生成、校验和失败后修订。

## 2. 范围与模块边界

- GenB 控制面：保存契约、实现、配置、绑定和凭证，解析有效绑定并签发短时 Actor Token。
- `PLANNING_REASONING_V1` 调用适配器：把 GenB 测试台统一输入转换为规划服务请求，规范化返回；不执行 Skill 或 MCP 工具。
- 规划服务：负责澄清、生成、校验和版本修订；继续独立部署在本地 `18712`。
- 测试智能体：只负责编排组件会话和规划服务调用；服务凭证只保存在智能体进程环境中。
- 页面：管理端提供组件级测试，客户端提供智能体级测试；不在浏览器保存或传输服务凭证。
- 本轮不实现 Skill 执行器，不调用 MCP 工具，不接入生产环境。

## 3. 成功标准

- [x] OpenAPI 契约可在 GenB 校验、发布和查看操作列表。
- [x] GenB 可注册 `PLANNING_REASONING_V1` 实现并发布配置。
- [x] 管理员服务直测无需智能体或服务凭证，可获得真实澄清/生成结果。
- [x] 智能体绑定测试必须通过有效服务凭证、用户权限和启用绑定后才能调用。
- [x] `standalone-planning-test-agent` 的页面可完成澄清、生成、校验和失败修订。
- [x] 绑定停用、错误凭证返回可识别失败，不绕过 GenB。
- [x] 后端、Python、管理端、客户端自动化测试及双语构建通过。
- [x] 本地真实 HTTP 与页面验收通过，文档、报告和记录索引同步。

## 5. 数据与安全约束

- 数据模型文档可表达逻辑关联，实际数据库迁移不创建物理外键。
- 远程开发库仅追加或更新本任务的测试记录，不批量删除、不覆盖他人数据。
- 服务凭证不进入 Git、页面、本地存储、日志或验收报告；一个智能体使用一个长期凭证。
- Actor Token 短时有效，并由规划服务校验组件、智能体、用户和 scope。
- Skill 正文按普通文本/Markdown 展示，不执行其中内容。

## 6. 回滚点

- 停止 `18713` 测试智能体即可撤销客户端调用入口。
- 停用 GenB 中的规划绑定或实现即可切断运行调用，不删除历史记录。
- 代码按 GenB 子仓与父仓精确提交，可按提交回退；不处理工作区既有生成物和无关修改。
