# 节点观测与管理生命周期

状态：采纳用于本轮实现，2026-09-15。承接 20260908 普通智能体独立路由与多节点执行 ADR。

采用固定 SSH 程序的只读 metrics 动作和控制面独立有界调度；不在 18 安装 exporter、Docker、Java 或监控数据库。保留未来大规模改用独立监控平台的可能，但本轮不引入第二套执行链路。

节点管理状态与环境/观测状态分离；PAUSED/DRAINING 不自动停业务、不释放端口。退役仅封存管理记录，活动依赖未清除时拒绝；旧实例恢复不能被暂停新部署误拦截。

资源是整机样本；工作负载是 GenB 已登记记录。项目 distinct agentId、实例 instanceId，过期运行状态只当最后观察。节点失联不写零负载、不自动迁移。

采样没有新 Redis 缓存；数据库保存最新样本及有限历史。协议升级先兼容控制面、后执行器；旧执行器明确不支持，不伪造实时数据。

详细参数、验收与范围见多节点完善计划 1.1 及 M0 基线。收益是低资源和复用身份；代价是 SSH 小规模采样开销、非实时观测，必须以 Q1—Q5 实测约束。
