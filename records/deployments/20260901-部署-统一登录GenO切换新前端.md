# 统一登录 GenO 切换新前端部署记录

日期：2026-09-01

## 目标

将 Genesis 统一登录点击 GenO 后的 callback 从后端服务器地址切换到统一前端服务器，并保证一次性 Ticket、GenO 换票、用户资料和刷新恢复完整可用。

目标链路：

```text
http://18.167.156.11/portal/login
  → http://18.167.156.11/geno/sso/callback?ticket=一次性凭证
  → http://18.167.156.11/geno/overview
```

## 变更前基线

- GenB 环境变量 `GENESIS_GENO_CALLBACK_URL` 指向 `http://47.116.69.17/geno/sso/callback`。
- `bank_agent_db.genesis_platforms` 中 `GEN_O` 的 `entry_url`、`login_url` 同样指向 47 地址。
- 新前端服务器的 `/geno/` 和 `/geno/sso/callback` 均能返回 GenO 前端页面。
- GenO 后端 CORS 仅包含 47 地址等旧来源，不包含 `http://18.167.156.11`。
- 后端服务器根分区使用率 48%，可用约 50 GiB。

## 实施内容

### GenB

- 将 `/app/gen-b-console/genesis.env` 中的 `GENESIS_GENO_CALLBACK_URL` 更新为 `http://18.167.156.11/geno/sso/callback`。
- 将 `bank_agent_db.genesis_platforms` 中 `GEN_O` 的 `entry_url`、`login_url` 更新为同一 callback。
- 使用现有 `stop.sh`、`start.sh` 受控重启 GenB。
- 首次 SQL 误带表中不存在的 `updated_at` 字段，被 PostgreSQL 拒绝；该次没有重启服务。随后按实际表结构只更新两个 URL 字段并成功提交。

### GenO

- 将 `/app/gen-o/.env` 和 `/app/gen-o/backend/.env` 的 `CORS_ALLOWED_ORIGINS` 增加 `http://18.167.156.11`。
- 只执行 `docker compose up -d --no-deps --force-recreate backend`，未重建镜像、未修改代码、未修改数据库、未重启 Celery、Reasoning 或 Onto Engine。

## 备份

- GenB 环境和数据库行：`/app/gen-b-console/backups/20260901_135808_geno_callback_to_frontend/`
- GenO CORS 环境：`/app/gen-o/backups/20260901_140333_geno_cors_frontend/`

## 验收结果

- GenB：`http://127.0.0.1:8581/api/actuator/health` 返回 `UP`。
- GenO：`http://127.0.0.1:7200/openapi.json` 返回成功，`gen-o-backend` 为 `healthy`。
- GenO CORS 预检返回 HTTP 200，`Access-Control-Allow-Origin` 为 `http://18.167.156.11`。
- 真实用户从统一门户点击 GenO 后：
  - Genesis Ticket 接口 HTTP 200。
  - 浏览器进入 `18.167.156.11/geno/sso/callback`。
  - GenO `/api/v1/auth/sso/exchange` HTTP 200。
  - GenO `/api/v1/auth/profile` HTTP 200。
  - 最终地址为 `http://18.167.156.11/geno/overview`，地址栏不再保留 Ticket。
  - 刷新后仍停留在 `/geno/overview`，没有出现统一登录失败。
- 部署后后端根分区仍为 48%，可用约 50 GiB。

## 回滚

如需回滚：

1. 使用上述 GenB 备份恢复 `genesis.env`，并把 `GEN_O` 的 `entry_url/login_url` 恢复为备份 CSV 中的值。
2. 使用上述 GenO 备份恢复两份 `.env`。
3. 使用现有脚本重启 GenB；执行 `docker compose up -d --no-deps --force-recreate backend` 重建 GenO 后端容器。
4. 重新验收 GenB 健康、GenO OpenAPI、CORS 和完整 SSO 链路。
