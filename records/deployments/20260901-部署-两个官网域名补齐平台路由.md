# 两个官网域名补齐平台路由部署记录

## 背景

`alaya.to` 与 `genesis-engine.ai` 的 Nginx 虚拟主机只配置了各自官网的 `location /`。因此访问 `/portal/login` 等平台路径时，被官网单页应用的 `index.html` 接管，无法进入 Genesis 统一登录。

## 变更范围

- 保留两个域名各自的官网根路径和现有 GenC 路由。
- 新增共享路由文件 `/etc/nginx/snippets/shared-platform-routes.conf`。
- 在两个域名虚拟主机中 include 同一份共享路由，不为每个项目新增独立 Nginx 主配置。
- 共享文件只接管 `/portal`、`/genb`、`/genb-en`、`/genb-client`、`/genb-client-en` 和 `/geno` 前缀。
- GenB 与 GenO 代理固定向后端传递已放行的 `Host: 47.116.69.17`，避免官网域名 Host 触发后端公网入口的备案拦截。

## 回滚

如需回滚，恢复备份目录中的 `frontends.conf` 和共享路由备份，执行 `nginx -t`，通过后再 reload。回滚只撤销本次域名平台路由，不应覆盖备份之后其他同事的 Nginx 修改。
