## 验收中处理的问题与边界

1. 47 的 systemd 239 不支持新版本的部分 CLI 参数：改用 oneshot 构建和 WorkingDirectory 属性，47 Python 实测通过。
2. Docker save 使用 OCI 布局：增加布局兼容与配置摘要验证。初版测试镜像自身缺少 httpd，健康检查正确判为不健康；换用服务器既有 Nginx 基础镜像后通过，未下载额外基础镜像。
3. 节点探测并发会覆盖观察版本：改为数据库行锁，保留管理员许可。列表不再以 47 本地进程状态覆盖远程实例状态，旧本地启停入口拒绝受管项目。
4. 浏览器曾遇到单次代理 502，重取成功；页面失败后现会继续轮询。连续 HTTP 验收中一次换票返回 401，独立重跑成功，原因尚未定位；未据此宣称完成网络故障或高并发压力验收。
5. 删除临时账号后，旧令牌被既有鉴权层以 HTTP 500 拒绝，账号确已不存在；这是既有失效用户响应语义问题，本轮未改鉴权过滤器。

不包含多副本、自动迁移、滚动替换、自动清理或新 HTTPS 域名。失败任务保留端口与材料用于排查。真实 FIBO、模型调用、Fuseki/Pellet 和应用业务数据隔离未冒充已验收。
