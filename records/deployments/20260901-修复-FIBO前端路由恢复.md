# FIBO 前端路由恢复记录

## 问题

`http://18.167.156.11/fibo/` 返回 Nginx 404。静态文件、FIBO 后端和受限 SSH 隧道均正常，当前统一 Nginx 配置中缺少 `/fibo/` 路由。

## 时间线与根因

- 2026-09-01 11:27 FIBO 首次部署并验收。
- 11:29 `/fibo/` 与 `/fibo/api/status` 仍返回 HTTP 200。
- 12:24 保存的平台路由变更前配置中已经没有 FIBO location，说明路由在 11:29 至 12:24 之间的一次 Nginx 覆盖中丢失。
- 后续 Nginx 合并以当时线上配置为基线，保留了这个既有缺口，没有在项目回归中检查 FIBO。

## 修复

只在默认 IP 虚拟主机恢复以下路由：

- `/fibo`：301 到 `/fibo/`。
- `/fibo/`、`/fibo/index.html`：读取 `/app/frontend/fibo/dist/index.html`。
- `/fibo/api/`：通过本机受限 SSH 隧道代理到 `127.0.0.1:8765/api/`。

未修改两个官网域名虚拟主机、共享平台路由、GenB、GenC、GenO 或统一登录配置。
